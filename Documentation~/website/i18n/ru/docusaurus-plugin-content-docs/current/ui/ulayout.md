# Адаптер uLayout

`Foundation.UI.ULayout` — необязательный адаптер для [uLayout](https://github.com/pokeblokdude/uLayout)
(`com.pokeblokdude.ulayout`) версии 1.7.1 или новее. Он компилируется только при установленном пакете и не
добавляет зависимостей в основную UI-сборку. Он предоставляет **подгонку по соотношению сторон** для uLayout.

## Иерархия {#hierarchy}

```text
Container (uLayout Layout)
  Slot (uLayout LayoutItem + ULayoutAspectRatioFitter)
    Content (RectTransform, Image, view, or a nested Layout)
```

Настройте **Slot** обычными средствами uLayout: размеры, flex-веса и отступы. Чтобы занять выделенное место,
включите Grow по обеим осям. На компоненте вписывания, добавленном к **Slot**, назначьте его непосредственный дочерний объект **Content**. *Aspect
Ratio* — ширина / высота; *Alignment* задаёт положение содержимого от левого нижнего угла (0, 0) до правого верхнего (1, 1),
по умолчанию центр. Компонент вписывает содержимое в слот без обрезки.

В режиме `ContainContent`:

- uLayout единолично владеет слотом, а компонент единолично владеет якорями, позицией и размерами содержимого,
  сохраняя его pivot.
- Не добавляйте к Content `AspectRatioFitter` или `ContentSizeFitter` Unity.
- Если у Content есть `LayoutItem` или `Layout` uLayout, используйте фиксированный размер по обеим осям, чтобы
  он не менял размер сам.
- Не добавляйте `Layout` на Slot: он стал бы раскладывать и Content.
- Content должен иметь единичный масштаб и не иметь локального поворота для прямоугольного вписывания.
- Слот сохраняет выделенные ему границы, включая свободные поля вокруг содержимого, когда родитель размещает
  соседей или вычисляет `FitContent`. Такое разделение исключает обратную связь между подгонкой по пропорциям,
  Grow и переносом элементов.

Подгонщик работает в Edit Mode и Play Mode, реагирует на завершение раскладки, изменение размера контейнера,
смену пропорции во время работы и смену родителя, а после стабилизации результата не пишет в transform
повторно. Родитель в виде обычного `RectTransform` тоже подходит. Соотношение сторон задаётся явно и не
определяется по спрайту или текстуре.

## Высота от ширины (адаптивный квадрат) {#height-from-width-an-adaptive-square}

Выберите **Fit Mode = Height From Width**, затем нажмите **Configure Slot: Grow Width / Fixed Height** в
инспекторе. Установите Aspect Ratio равным **1** для квадрата. uLayout назначает слоту ширину после отступов
контейнера и полей элемента, а компонент вычисляет высоту слота по формуле «ширина / соотношение сторон».
Вертикальная раскладка измеряет эту высоту до размещения следующих элементов, в том числе когда родитель
использует `FitContent` по высоте.

Этот режим работает и без дочернего Content (например, с `Image` прямо на Slot). Grow Y должен быть выключен,
потому что он отдаёт управление высотой родителю, а не пропорции. Существующие компоненты остаются в режиме
`ContainContent`.
